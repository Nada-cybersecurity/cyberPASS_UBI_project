**Selected: AfriEU CyberPass.** A judge understands it without explanation: Africa, EU, cybersecurity, passport. Risks: "AfriEU" can be read several ways (say "Afri-E-U"), and "EU" in a name must never be paired with the EU emblem or wording that suggests official endorsement. **StraitPass** is the best fallback for a later rebrand; the "14 km" story already lives in the pitch. The name is set in one place: `src/brand.ts`.
